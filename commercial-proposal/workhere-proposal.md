# WorkHere
## ATS/CRM для подбора персонала

---

**WorkHere** — единое пространство для ведения вакансий, кандидатов и коммуникаций. Ускоряет закрытие вакансий за счёт автоматизации, единой базы и аналитики воронки.

---

## Для кого

| Роль | Ценность |
|------|----------|
| **HR-директора** | Прозрачность воронки, контроль качества, аналитика |
| **Рекрутеры** | Быстрый поиск, единая база, автоматизация рутины |
| **HR-универсалы** | Интеграции с 1С, передача данных о сотрудниках |

Подходит для компаний с регулярным наймом, агентств и in-house рекрутинга.

---

## Проблемы → Решения

| Боль | Как решает WorkHere |
|------|---------------------|
| Кандидаты в почте, таблицах, мессенджерах — теряются | Единая база с полной историей |
| Нет контроля этапов и конверсии | Воронка с аналитикой каждого шага |
| Много ручной рутины | Автоматизация действий и напоминания |
| Дубли кандидатов | Автодедупликация и объединение |
| Долгий поиск по базе | ИИ-поиск по смыслу, не только по словам |
| Нужна интеграция с 1С | Готовые интеграции и открытый API |

---

## Ключевой функционал

**Управление подбором**
- Воронка/канбан с гибкими стадиями
- Карточка кандидата: контакты, резюме, теги, история
- Задачи и напоминания по кандидатам

**Прозрачность**
- История всех действий и коммуникаций
- Модуль согласований с нанимающими менеджерами

**Аналитика**
- Конверсия этапов, скорость закрытия
- Эффективность источников кандидатов

---

## Интеграции

- **Джоб-сайты** — автоимпорт откликов и резюме
- **Мессенджеры** — фиксация диалогов в карточке
- **1С и внешние системы** — открытый API

---

## ИИ-поиск

Модуль интеллектуального поиска: находит кандидатов по смыслу, ранжирует результаты, экономит время при повторном закрытии вакансий.
