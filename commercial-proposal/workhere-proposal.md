# WorkHere

## ATS/CRM-система для подбора персонала

---

## О продукте

**WorkHere** — это современная ATS/CRM-система для подбора персонала: единое пространство, где команда рекрутинга ведёт вакансии, кандидатов и коммуникации.

Система ускоряет закрытие вакансий за счёт:
- Автоматизации рутинных процессов
- Единой базы кандидатов
- Аналитики воронки найма
- Модулей интеграций (джоб-сайты, мессенджеры, 1С и др.)

- Полная прозрачность воронки найма

## Какие проблемы решает WorkHere

| Проблема | Решение WorkHere |
|----------|------------------|
| Кандидаты и отклики «размазаны» по почте, таблицам и мессенджерам — теряются, дублируются, нет истории | Единая база с полной историей всех действий и коммуникаций |
| Нет контроля по этапам и конверсии — сложно понять, где «узкое горлышко» | Воронка с аналитикой конверсии на каждом этапе |
| Много ручной рутины: перенос резюме, статусы, напоминания, письма | Автоматизация типовых действий и напоминания |
| Дубли кандидатов в разных источниках — хаос и ошибки | Автоматическая дедупликация и объединение карточек |
| Невозможно быстро найти кандидата — каждый раз «ищем с нуля» | Мощный поиск по базе + ИИ-модуль для смыслового поиска |
| Нужна интеграция с 1С и внутренними системами | Готовые интеграции и открытый API |

## Ключевой функционал

### Управление вакансиями
- Воронка/канбан для визуального управления этапами подбора
- Гибкая настройка стадий под ваши процессы

### Карточка кандидата
- Контактные данные
- Резюме и файлы
- Теги для быстрой фильтрации
- Комментарии команды
- Полная история действий

### Прозрачность процессов
- История коммуникаций и событий по каждому кандидату
- Видно, кто и что делал на каждом этапе

### Дедупликация
- Автоматическое обнаружение дублей по телефону, e-mail и другим признакам
- Объединение карточек в один клик

### Задачи и напоминания
- Напоминания по кандидатам и вакансиям
- Контроль касаний — ни один кандидат не будет забыт

### Работа с заказчиками
- Модуль для коммуникации с нанимающими менеджерами
- Согласования внутри процесса найма

### Отчёты и аналитика
- Воронка найма
- Конверсия этапов
- Скорость закрытия вакансий
- Эффективность источников кандидатов

## ИИ-поиск кандидатов

**Отдельный модуль интеллектуального поиска** по базе кандидатов:

- **Смысловой поиск** — находит релевантных кандидатов не только по ключевым словам, но и по смыслу
- **Умное ранжирование** — лучшие кандидаты в топе выдачи
- **Экономия времени** — быстрое повторное закрытие типовых вакансий
