# WorkHere Hero Background

Анимированный фон в стиле "переливающегося шёлка" для лендинга WorkHere.

## Файлы

| Файл | Описание |
|------|----------|
| `index.html` | Полная версия с демо-контролами |
| `hero-bg-minimal.html` | Минимальная версия |
| `HeroBackground.jsx` | React-компонент |

## Демо

Открой `index.html` в браузере. Используй слайдеры внизу справа для настройки интенсивности и скорости.

## Кастомизация

### CSS Variables

```css
:root {
  /* Цвета */
  --wh-blue: #1890ff;           /* Фирменный голубой (края) */
  --center-accent: #ff3b8d;      /* Фуксия (центр) */
  --bg-base: #f8f9fc;            /* Базовый фон */
  
  /* Настройки эффекта */
  --intensity: 0.85;             /* 0.0 - 1.0 */
  --speed: 1;                    /* 0.5 - 1.5 */
}
```

### Изменение интенсивности

- `--intensity: 0.5` — очень деликатный эффект
- `--intensity: 0.85` — рекомендуемое значение
- `--intensity: 1.0` — максимальный эффект

### Изменение скорости

- `--speed: 0.5` — очень медленно (циклы ~50-80 сек)
- `--speed: 1.0` — нормально (циклы ~22-40 сек)
- `--speed: 1.5` — быстрее (циклы ~15-27 сек)

## Структура слоёв

1. **Base** — светлый градиент (off-white)
2. **Center Glow** — центральное свечение фуксии
3. **Edge Glows** — голубые подсветки по углам
4. **Blobs** — анимированные градиентные пятна
5. **Grain** — лёгкий шум для "дорогого" эффекта

## React использование

```jsx
import HeroBackground from './HeroBackground';

function App() {
  return (
    <HeroBackground 
      intensity={0.85} 
      speed={1}
      blueColor="#1890ff"
      accentColor="#ff3b8d"
    >
      <h1>Ваш контент</h1>
    </HeroBackground>
  );
}
```

## Accessibility

- Поддержка `prefers-reduced-motion` — при включённой настройке анимация отключается
- Текст читаем на фоне (проверен контраст)
- Fallback для старых браузеров (статичный градиент)

## Производительность

- GPU-ускорение через `transform` и `will-change`
- Без тяжёлых JS-библиотек
- Анимация на CSS (60fps)
- Размытие через `filter: blur()` (оптимизировано браузером)

## Интеграция

### Простое копирование (HTML/CSS)

1. Скопируй содержимое `<style>` из `index.html`
2. Скопируй HTML-структуру `.wh-hero`
3. Замени контент в `.wh-hero__content`

### Next.js / React

1. Скопируй `HeroBackground.jsx` в `components/`
2. Импортируй и используй как обёртку
